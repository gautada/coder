# coder

A web based code editor container this is intended to be an exposed container
that allows for editing code from anywhere.  The idea is to have and IDE that
can work from anywhere in the world.

This environment will be based on three bases

1. [nvim-server](https://github.com/Kraust/nvim-server/tree/main) - NVIM is my
person choice for development and code editing, this project is nascent but
may work very well.
2. [Code Server](https://github.com/coder/code-server)
3. wetty
